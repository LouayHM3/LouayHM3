## 👋 About me

I'm a final-year **Telecommunications & Networks Engineering student at ENIT** in Tunis, specializing in **Converged Infrastructures, Cloud & Cybersecurity**.

I enjoy building systems where **AI, cybersecurity, cloud infrastructure and networked systems** meet. My current interests include security automation, RAG applications, LLM evaluation, SOC tooling, cloud-native security and reliable agentic workflows.

- 🔭 Working on AI-assisted cybersecurity and secure automation
- 🧠 Exploring RAG, LLM security, agent orchestration and SOC copilots
- ☁️ Building with AWS, Docker, Kubernetes and cloud-native security tools
- 🌐 Interested in networks, distributed systems and intelligent infrastructure
- 🥋 Two-time Tunisian national taekwondo champion and former national-team member
- 🇹🇳 Based in Tunis, Tunisia
